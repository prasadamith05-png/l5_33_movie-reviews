# Documented Static Code Analysis Issues

The table below documents the security, code quality, design, and style issues identified by **Bandit**, **Pylint**, and **Flake8** in `movie_reviews.py`, prioritized by severity (High and Medium severity first), along with the rationale and fix approaches applied.

| Issue | Type | Line(s) | Description | Fix Approach |
|---|---|---|---|---|
| Insecure MD5 Hash Algorithm | Security (Bandit B324, High) | 46 | `hashlib.md5()` was called without specifying security usage. MD5 is cryptographically weak and prone to collision attacks. | Pass `usedforsecurity=False` (or migrate to SHA-256) to make explicit that MD5 is used solely for non-cryptographic identifier generation. |
| Insecure Network Interface Binding | Security (Bandit B104, Medium) | 4 | `STREAM_HOST = "0.0.0.0"` binds the server endpoint to all network interfaces, exposing internal service endpoints to untrusted public networks. | Restrict host binding to `127.0.0.1` (localhost) or retrieve the binding address dynamically from environment configuration. |
| Hardcoded Authentication Secret | Security (Bandit B105, Low) | 6 | `MODERATOR_PASSWORD = "reviews-demo"` embedded a plain-text authentication credential directly into source code. | Avoid embedding secrets in code; read credentials dynamically via `os.getenv("MODERATOR_PASSWORD", "")`. |
| Cryptographically Insecure Pseudo-Random Generator | Security (Bandit B311, Low) | 2, 41 | `random.choice()` uses Python's pseudo-random generator (Mersenne Twister), which is deterministic and insecure for security-sensitive workflows. | Replace `random.choice()` with `secrets.choice()` from the standard library `secrets` module. |
| Missing Module and Function Docstrings | Code Quality (Pylint C0114, C0116) | 1, 11, 16, 26, 34, 39, 45, 48, 54, 58 | Neither the module nor its functions provided docstrings detailing functionality, arguments, or return values. | Add comprehensive PEP 257-compliant docstrings to the module header and every function. |
| Non-snake_case Naming Conventions | Code Quality (Pylint C0103) | 11, 16, 26, 34, 39, 45, 48, 54 | Functions (`addMovie`, `rateMovie`, `averageRating`, etc.) and parameter names (`reviewText`) used camelCase contrary to PEP 8 standards. | Refactor function names and parameters to standard Python snake_case (e.g., `add_movie`, `rate_movie`, `review_text`). |
| Global Variable Mutation and Anti-Pattern | Code Smell / Design (Pylint W0603, C0103) | 8, 40-41 | `pickFeatured()` relied on `global featured` to mutate a module-level variable `featured = None`, introducing mutable state and tight coupling. | Eliminate `global featured` and `featured = None`; have `pick_featured()` return the chosen movie directly. |
| Unnecessary Else After Return | Code Quality (Pylint R1705) | 28-31 | `averageRating()` included an unnecessary `else` block after an unconditional `return` statement in the `if` block. | Remove the redundant `else` and de-indent `return 0.0` for cleaner control flow. |
| Iteration Using `range(len(...))` | Code Quality (Pylint C0200) | 50 | `printAllReviews()` iterated over indices with `range(len(titles))` and indexed `titles[i]`, which is unidiomatic in Python. | Refactor loop to use `enumerate(titles, start=1)` for clean, idiomatic iteration over index and title simultaneously. |
| Missing Whitespace Around Operators | Style (Flake8 E225) | 35 | `ranked=sorted(...)` omitted whitespace surrounding the assignment operator `=`. | Add spaces around the assignment operator: `ranked = sorted(...)`. |
| Insufficient Blank Lines Between Functions | Style (Flake8 E302) | 48 | Only one blank line preceded `def printAllReviews()`, violating PEP 8's two-blank-line requirement. | Insert an extra blank line to ensure two blank lines separate top-level definitions. |
| Inline Comment Formatting | Style (Flake8 E261) | 70 | Inline comment `# demo id` had only a single space before `#` instead of at least two spaces. | Add two spaces before `# demo id`. |
| Missing Whitespace After Comma | Style (Flake8 E231) | 72 | `print("Genres:",sorted(...))` omitted whitespace following the comma separator. | Insert a space after the comma: `print("Genres:", sorted(...))`. |
